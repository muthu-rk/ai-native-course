How we will learn

Predict → inspect a contrasting case → build intuition → try a small experiment → explain a new case.

Your prerequisite level is untested. Lessons begin from the application’s visible behavior and introduce deeper concepts when needed.

Practical milestones: one hosted call → a controlled tool loop → a Pi implementation → an OpenClaw trace → a measured self-hosted backend.

This course uses the Codex adaptation of your explain-system skill. The diagrams and demo are local teaching material; they do not call a model.
